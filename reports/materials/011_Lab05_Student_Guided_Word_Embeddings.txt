# PHẦN A — TỪ TF-IDF SANG WORD EMBEDDING

Buổi 4:

```text
ô_tô != xe_hơi
```

Trong TF-IDF, hai token là hai chiều vocabulary khác nhau.

Word2Vec đặt câu hỏi khác:

> Những từ nào thường xuất hiện trong **context tương tự**?

Nếu hai từ được dùng trong context giống nhau, vector của chúng có thể nằm gần nhau hơn.

[5: markdown]
## Sparse vs Dense

### TF-IDF
```text
document → [0, 0, 0.42, 0, 0.18, ...]
```

- dimension ≈ vocabulary size;
- sparse;
- feature có tên rõ.

### Word2Vec
```text
word → [0.12, -0.38, 0.74, ..., 0.05]
```

- dimension = `vector_size`;
- dense;
- mỗi dimension thường không có ý nghĩa độc lập rõ ràng.

def build_sentences(subjects, contexts, repeat=8):
    sentences = []

    for _ in range(repeat):
        random.shuffle(subjects)
        random.shuffle(contexts)

        for s in subjects:
            c = random.choice(contexts)
            sentences.append(f"{s} {c}")

    return sentences

## Key discussion — Similar ≠ Synonym

Nếu:

```text
vàng → bitcoin, cổ_phiếu, tỷ_giá...
```

không có nghĩa các từ này đồng nghĩa.

Nó có thể chỉ có nghĩa:

> Chúng xuất hiện trong những context tài chính tương tự.

Word2Vec học **distributional similarity**, không học từ điển synonym.

def train_sample_model(
    window=5,
    min_count=1,
    vector_size=50,
    epochs=30,
    sg=1
):
    return Word2Vec(
        sentences=sample_sentences,
        vector_size=vector_size,
        window=window,
        min_count=min_count,
        workers=1,
        epochs=epochs,
        sg=sg,
        seed=42,
    )

model_w2 = train_sample_model(
    window=2
)

model_w8 = train_sample_model(
    window=8
)

print("window=2:")
print(
    model_w2.wv.most_similar(
        "vàng",
        topn=5
    )
)

print("\nwindow=8:")
print(
    model_w8.wv.most_similar(
        "vàng",
        topn=5
    )
)

def average_document_vector(tokens, model):
    vectors = [
        model.wv[token]
        for token in tokens
        if token in model.wv
    ]

    if not vectors:
        return np.zeros(
            model.wv.vector_size,
            dtype=np.float32
        )

    return np.mean(vectors, axis=0)

def find_similar_documents(
    doc_index,
    document_vectors,
    data,
    top_k=5
):
    query = document_vectors[doc_index].reshape(1, -1)
    scores = cosine_similarity(query, document_vectors)[0]

    ranked = np.argsort(scores)[::-1]
    ranked = [
        idx for idx in ranked
        if idx != doc_index
    ][:top_k]

    columns = ["title"]

    if "category" in data.columns:
        columns.append("category")

    result = data.iloc[ranked][columns].copy()

    result["similarity"] = [
        float(scores[idx])
        for idx in ranked
    ]

    return result

def document_coverage(tokens, model):
    if not tokens:
        return 0.0

    in_vocab = sum(
        token in model.wv
        for token in tokens
    )

    return in_vocab / len(tokens)

# PHẦN 7 — FINAL DECISION

Chọn một cấu hình cuối cùng và giải thích trade-off.

| Parameter | Final value | Vì sao chọn? | Trade-off |
|---|---:|---|---|
| `vector_size` | 100 | Đủ sức biểu diễn corpus 491 bài | Train và lưu trữ tốn hơn 50 chiều |
| `window` | 5 | Cân bằng context cục bộ và chủ đề rộng | Có thể bỏ lỡ quan hệ xa hơn |
| `min_count` | 2 | Loại token chỉ xuất hiện một lần nhưng giữ phần lớn từ hiếm | Một số tên riêng quan trọng có thể thành OOV |
| `epochs` | 30 | Cho corpus vừa/nhỏ học lặp đủ nhiều | Thời gian train tăng |
| `sg` | 1 | Skip-gram phù hợp hơn với từ ít gặp | Chậm hơn CBOW |
