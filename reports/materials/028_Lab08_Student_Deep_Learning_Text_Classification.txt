## TASK 1 — SHAPE TRACE

Không cần viết thêm model. Hãy đọc output notebook và điền ý nghĩa các shape.

### Bảng cần hoàn thành

| Stage | Shape | Ý nghĩa |
|---|---|---|
| Padded input | `(320, MAX_LEN)` | ? |
| After Embedding | `(320, MAX_LEN, EMBEDDING_DIM)` | ? |
| After Conv1D | `(...)` | ? |
| After GlobalMaxPooling1D | `(...)` | ? |
| Final output | `(320, 1)` hoặc theo batch | ? |

### Gợi ý

Với CNN hiện tại:

```python
Conv1D(
    filters=64,
    kernel_size=3,
)
```

nếu `padding="valid"` thì:

```text
sequence_length_after_conv
=
MAX_LEN - kernel_size + 1
```

Ví dụ `MAX_LEN = 72`:

```text
72 - 3 + 1 = 70
```

Do đó shape có thể đi theo flow:

```text
(320, 72)
    ↓ Embedding(32)
(320, 72, 32)
    ↓ Conv1D(filters=64, kernel_size=3)
(320, 70, 64)
    ↓ GlobalMaxPooling1D
(320, 64)
    ↓ Dense
...
    ↓ Output
(320, 1)
```

> Mục tiêu của task này là hiểu **mỗi chiều đang đại diện cho gì**, không phải học thuộc con số.

def build_cnn_model(
    vocab_size,
    max_len,
    embedding_dim=32,
    filters=64,
):
    model = keras.Sequential([
        layers.Input(shape=(max_len,)),
        layers.Embedding(
            input_dim=vocab_size,
            output_dim=embedding_dim,
        ),
        layers.Conv1D(
            filters=filters,
            kernel_size=3,
            activation="relu",
        ),
        layers.GlobalMaxPooling1D(),
        layers.Dropout(0.30),
        layers.Dense(32, activation="relu"),
        layers.Dropout(0.20),
        layers.Dense(1, activation="sigmoid"),
    ])

    model.compile(
        optimizer="adam",
        loss="binary_crossentropy",
        metrics=["accuracy"],
    )

    return model


cnn_model = build_cnn_model(
    VOCAB_SIZE,
    MAX_LEN,
    embedding_dim=EMBEDDING_DIM,
)

cnn_model.summary()

def evaluate_dl_model(name, model, X_test, y_test):
    scores = model.predict(X_test, verbose=0).reshape(-1)
    pred = (scores >= 0.5).astype(int)

    row = {
        "model": name,
        "accuracy": accuracy_score(y_test, pred),
        "precision_macro": precision_score(
            y_test, pred, average="macro", zero_division=0
        ),
        "recall_macro": recall_score(
            y_test, pred, average="macro", zero_division=0
        ),
        "f1_macro": f1_score(
            y_test, pred, average="macro", zero_division=0
        ),
    }

    return row, pred, scores


cnn_row, cnn_pred, cnn_scores = evaluate_dl_model(
    "CNN",
    cnn_model,
    X_test_pad,
    y_test,
)

print()
print(classification_report(
    y_test,
    cnn_pred,
    target_names=[ID_TO_LABEL[0], ID_TO_LABEL[1]],
    zero_division=0,
))

def build_lstm_model(
    vocab_size,
    max_len,
    embedding_dim=32,
    lstm_units=32,
):
    model = keras.Sequential([
        layers.Input(shape=(max_len,)),
        layers.Embedding(
            input_dim=vocab_size,
            output_dim=embedding_dim,
        ),
        layers.LSTM(
            lstm_units,
            dropout=0.20,
        ),
        layers.Dense(32, activation="relu"),
        layers.Dropout(0.30),
        layers.Dense(1, activation="sigmoid"),
    ])

    model.compile(
        optimizer="adam",
        loss="binary_crossentropy",
        metrics=["accuracy"],
    )

    return model
