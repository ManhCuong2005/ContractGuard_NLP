Mục tiêu của Buổi 6
Hiểu bài toán supervised text classification: X, y, label.
Chia train/test đúng cách và tránh data leakage.
Xây pipeline TF-IDF + classifier bằng scikit-learn.

Key message: cùng một pipeline, chỉ thay classifier thì so sánh mới công bằng.

Classifier 3: Linear SVM
Trực giác hình học
Boundary
SVM tìm đường phân tách các document vectors.
Linear SVM là baseline mạnh cho TF-IDF sparse vector.
Code pattern: chỉ thay classifier
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
pipe = Pipeline([
("tfidf", TfidfVectorizer()),
("clf", LinearSVC())
])
pipe.fit(X_train, y_train)
y_pred = pipe.predict(X_test)
Đổi model ở dòng "clf" nhưng giữ nguyên phần 
còn lại.
Pipeline = representation + classifier nằm trong cùng một object.
