```text

   ↓
Measure again
```

## 3.1 Cách nhớ metric

### Precision

> Trong những mẫu model **dự đoán là class X**, bao nhiêu mẫu thực sự là X?

### Recall

> Trong tất cả mẫu **thực sự thuộc class X**, model tìm được bao nhiêu?

### F1

Một chỉ số tổng hợp khi muốn cân bằng Precision và Recall.

### Macro vs Weighted

- **Macro:** mỗi class được tính trọng số như nhau.
- **Weighted:** class có nhiều mẫu hơn đóng góp nhiều hơn.

Với class imbalance, **Macro F1** là metric rất đáng theo dõi.

Hàm dưới được cung cấp để tất cả experiment:

[27: code]
MINORITY_CLASS = work_df[LABEL_COL].value_counts().idxmin()
print("Minority class:", MINORITY_CLASS)

def run_experiment(
    name,
    text_column=TEXT_COL,
    tfidf_kwargs=None,
    class_weight=None,
):
    if tfidf_kwargs is None:
        tfidf_kwargs = BASELINE_TFIDF.copy()

    vectorizer = TfidfVectorizer(**tfidf_kwargs)

    X_train = vectorizer.fit_transform(
        train_df[text_column].astype(str)
    )
    X_test = vectorizer.transform(
        test_df[text_column].astype(str)
    )

    model = LinearSVC(
        random_state=42,
        class_weight=class_weight,
    )
    model.fit(X_train, y_train)

    pred = model.predict(X_test)

    class_recalls = recall_score(
        y_test,
        pred,
        labels=labels,
        average=None,
        zero_division=0,
    )
    recall_by_class = dict(zip(labels, class_recalls))

    row = {
        "experiment": name,
        "text_input": text_column,
        "accuracy": accuracy_score(y_test, pred),
        "precision_macro": precision_score(
            y_test, pred, average="macro", zero_division=0
        ),
        "recall_macro": recall_score(
            y_test, pred, average="macro", zero_division=0
        ),
        "f1_macro": f1_score(
            y_test, pred, average="macro", zero_division=0
        ),
        "minority_recall": recall_by_class[MINORITY_CLASS],
        "n_features": X_train.shape[1],
    }

    return row, pred, vectorizer, model

## EXPERIMENT MENU — Gợi ý cho Experiment 3

Ngoài hai experiment bắt buộc ở trên, bạn hãy **chọn ít nhất 1 hướng** dưới đây để thử.

> Nguyên tắc: mỗi experiment nên có **lý do thử**, chỉ thay đổi **một yếu tố chính**, sau đó so sánh với baseline bằng cùng test set.

### 1. BoW vs TF-IDF

Giữ nguyên classifier, thay cách biểu diễn:

```text
Bag of Words
vs
TF-IDF
```

Gợi ý:

```python
from sklearn.feature_extraction.text import CountVectorizer
```

Câu hỏi:
- TF-IDF có thực sự tốt hơn BoW trên corpus này không?
- Metric nào thay đổi rõ nhất?

### 2. Resampling để xử lý class imbalance

Có thể thử:

```text
Oversampling minority class
hoặc
Undersampling majority class
```

Lưu ý:
- **Chỉ resample TRAIN set**.
- Không resample TEST set.
- So sánh đặc biệt `minority_recall` và `f1_macro`.

Câu hỏi:
- Recall của class thiểu số có tăng không?
- Accuracy có giảm không?
- Trade-off đó có đáng chấp nhận không?

### 3. Thử đầu vào khác nhau

Nếu dữ liệu có các cột `title`, `description`, `text`, có thể so:

```text
title
vs
title + description
vs
full content
```

Ví dụ:

```python
df["title_desc"] = (
    df["title"].fillna("") + " " +
    df["description"].fillna("")
)
```

Câu hỏi:
- Có phải càng nhiều text thì model càng tốt?
- Title có đủ tín hiệu để phân loại không?

### 4. Điều chỉnh tham số model

Giữ nguyên TF-IDF và thử **một tham số** của classifier.

Ví dụ với Linear SVM:

```python
LinearSVC(C=0.5)
LinearSVC(C=1.0)
LinearSVC(C=2.0)
```

Hoặc Logistic Regression:

```python
LogisticRegression(C=0.5)
LogisticRegression(C=2.0)
```

Câu hỏi:
- Tham số mới có cải thiện Macro F1 không?
- Kết quả thay đổi thế nào so với baseline?

### 5. Xử lý từ ghép tiếng Việt

So sánh:

```text
"thị trường chứng khoán"
```

với phiên bản word-segment:


Câu hỏi:
- Việc giữ từ ghép có giúp vocabulary phản ánh nghĩa tốt hơn không?
