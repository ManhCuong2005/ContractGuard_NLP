# LAB 06 — STUDENT GUIDED LAB
## Text Classification I — One Pipeline, Many Classifiers

### Mục tiêu

Sau lab này, bạn có thể:

1. Xác định `X` và `y` trong một bài toán text classification.
2. Chia dữ liệu thành train/test đúng cách.
3. Fit TF-IDF **chỉ trên train set** để tránh data leakage.
4. Huấn luyện và so sánh:
   - Multinomial Naive Bayes
   - Logistic Regression
   - Linear SVM
5. Đọc Accuracy, Precision, Recall, F1 và Confusion Matrix ở mức cơ bản.
6. Lưu prediction để chuẩn bị cho Error Analysis ở Buổi 7.

> **Key idea:** Giữ cùng dataset, preprocessing, split và representation; chỉ thay classifier để so sánh công bằng.

work_df = df.dropna(subset=[TEXT_COL, LABEL_COL]).copy()
work_df[TEXT_COL] = work_df[TEXT_COL].astype(str).str.strip()
work_df[LABEL_COL] = work_df[LABEL_COL].astype(str).str.strip()
work_df = work_df.loc[work_df[TEXT_COL].ne("") & work_df[LABEL_COL].ne("")].copy()
work_df = work_df.loc[work_df[LABEL_COL].isin(["Kinh doanh", "Công nghệ"])].copy()

### CHECKPOINT — `X_train`, feature và `y_train` là gì?

Sau khi chạy TF-IDF, hãy đọc shape như sau:

```text
X_train_text
= các chuỗi văn bản train
        │
        │  TF-IDF
        ▼
X_train
= feature matrix
```

Ví dụ nếu output là:

```text
Train matrix: (320, 742)
Test matrix : (80, 742)
Vocabulary  : 742
```

thì:

- `320` = số document trong train set;
- `80` = số document trong test set;
- `742` = số **features** trong vocabulary;
- mỗi document được biểu diễn bởi một **vector 742 chiều**;
- mỗi thành phần của vector tương ứng với một feature;
- giá trị của thành phần đó là trọng số TF-IDF.

Vì đang dùng:

```python
ngram_range=(1, 2)
```

một feature có thể là **unigram hoặc bigram**.

Trong khi đó:

```text
y_train / y_test
```

vẫn là các label như:

```text
"Công nghệ"
"Kinh doanh"
```

và không cần tự chuyển thành `0/1` khi dùng các classifier của scikit-learn.

def evaluate_model(name, model, X_train, y_train, X_test, y_test):
    model.fit(X_train, y_train)
    pred = model.predict(X_test)

    row = {
        "model": name,
        "accuracy": accuracy_score(y_test, pred),
        "precision_macro": precision_score(
            y_test, pred, average="macro", zero_division=0
        ),
        "recall_macro": recall_score(
            y_test, pred, average="macro", zero_division=0
        ),
        "f1_macro": f1_score(
            y_test, pred, average="macro", zero_division=0
        ),
    }

    return row, pred, model
