## 📌 CHEAT SHEET — POS Tag

`pos_tag()` trả về:

```text
(token, POS_tag)
```

### Các tag thường gặp

| Tag | Ý nghĩa | Ví dụ |
|---|---|---|
| `N` | Danh từ | người, ngày, công ty |
| `Np` | Danh từ riêng | Nguyễn Văn An, Đà Nẵng |
| `Nc` | Danh từ chỉ loại | con, cái, chiếc |
| `Nu` | Danh từ đơn vị | đồng, m, tuổi |
| `Ny` | Danh từ viết tắt | VN, TP, UBND |
| `V` | Động từ | đi, làm, tuyển |
| `A` | Tính từ | lớn, đẹp, mới |
| `P` | Đại từ | tôi, mình, này, đó |
| `R` | Phó từ / trạng từ | không, đã, cũng, lại |
| `L` | Định từ | những, các, mọi |
| `M` | Số từ | một, 100, triệu |
| `E` | Giới từ | của, trong, với, ở, cho |
| `C` | Liên từ | nhưng, mà, như |
| `I` | Thán từ | ôi, ơi, ạ |
| `T` | Trợ từ | cả, ngay, chính |
| `CH` | Dấu câu / ký tự đặc biệt | `,` `.` `?` |
| `X` | Không phân loại / khó xác định | tùy trường hợp |

### Tag mở rộng / ít gặp

| Tag | Ý nghĩa gần đúng |
|---|---|
| `Ab` | Tính từ mượn |
| `B` | Từ mượn |
| `Cc` | Biến thể nhãn liên từ theo corpus |
| `Fw` / `FW` | Từ nước ngoài |
| `Nb` | Danh từ mượn |
| `Ne` | Nhóm danh từ/chỉ loại, corpus-specific |
| `Ni` | Danh từ ký hiệu |
| `NNP` | Danh từ riêng trong một số corpus |
| `Ns` | Danh từ chỉ người/xưng hô |
| `S` | Thành tố/chức danh bổ nghĩa |
| `Vb` | Động từ mượn |
| `Vy` | Động từ viết tắt |
| `Y` | Nhãn hiếm, corpus-specific |
| `Z` | Yếu tố cấu tạo từ |

> Không cần học thuộc toàn bộ. Nhóm cốt lõi: `N`, `Np`, `V`, `A`, `P`, `R`, `M`, `E`, `CH`.

## 📌 Cách đọc output `ner()`

Model thường trả:

```text
(token, POS, Chunk, NER)
```

Ví dụ:

```text
('Nguyễn Văn An', 'Np', 'B-NP', 'B-PER')
```

- `Nguyễn Văn An` — token.
- `Np` — danh từ riêng.
- `B-NP` — bắt đầu một cụm danh từ.
- `B-PER` — bắt đầu một thực thể người.

Ví dụ:

```text
(',', 'CH', 'O', 'O')
```

- `CH` = dấu câu.
- `O` ở cột Chunk = ngoài chunk.
- `O` ở cột NER = không phải named entity.

[19: markdown]
## 📌 CHEAT SHEET — Chunking

BIO:

| Ký hiệu | Nghĩa |
|---|---|
| `B-` | Beginning — bắt đầu cụm |
| `I-` | Inside — nằm tiếp trong cụm |
| `O` | Outside — ngoài cụm |

Loại cụm:

| Tag | Ý nghĩa |
|---|---|
| `NP` | Noun Phrase — cụm danh từ |
| `VP` | Verb Phrase — cụm động từ |
| `PP` | Prepositional Phrase — cụm giới từ |
| `AP` | Adjective Phrase — cụm tính từ |

Ví dụ: `B-NP`, `I-NP`, `B-VP`, `B-PP`, `B-AP`.

**POS** hỏi “token là loại từ gì?”, còn **Chunking** hỏi “token nằm trong cụm gì?”.

[20: markdown]
## 📌 CHEAT SHEET — NER

| Entity | Ý nghĩa |
|---|---|
| `PER` | Person — người |
| `LOC` | Location — địa điểm |
| `ORG` | Organization — tổ chức |
| `O` | Không thuộc các entity trên |

Kết hợp BIO:

- `B-PER`, `I-PER`
- `B-LOC`, `I-LOC`
- `B-ORG`, `I-ORG`
- `O`

> NER là **dự đoán của model**, không phải chân lý.
