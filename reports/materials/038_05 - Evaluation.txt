Types of edit distance
•Different types of edit distance allow different sets of string operations. 
For instance:
• The Levenshtein distance allows deletion, insertion and substitution.
• The Longest common subsequence (LCS) distance allows only insertion and 
deletion, not substitution.
• The Hamming distance allows only substitution, hence, it only applies to strings of 
the same length.
• The Damerau–Levenshtein distance allows insertion, deletion, substitution, and 
the transposition of two adjacent characters.
• The Jaro distance allows only transposition.
