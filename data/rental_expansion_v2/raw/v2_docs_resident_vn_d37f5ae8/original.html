Hợp đồng thuê

Ở màn Mẫu hợp đồng thuê, bạn tạo sẵn mẫu hợp đồng để mỗi lần ký với khách chỉ việc in ra, không phải gõ lại từ đầu.
Hợp đồng nào cũng theo cùng một kiểu nên bạn đỡ mất thời gian, ít nhầm và khách nhìn cũng rõ ràng.

1. Những thông tin bạn thấy trên màn hình

Trong danh sách mẫu, bạn thấy các cột:

  • Mã: Mã hợp đồng, Resident tự đặt.
  • Tên mẫu: Tên của mẫu hợp đồng thuê (ví dụ: Hợp đồng thuê ngắn hạn, Hợp đồng thuê dài hạn…).
  • Xem mẫu PDF: Xem trước nội dung mẫu hợp đồng dưới dạng file PDF.
  • Mặc định: Chọn một mẫu làm mẫu dùng sẵn cho các lần sau.
  • Thao tác:
    • Sửa (biểu tượng bút tím): Sửa thông tin hoặc nội dung mẫu hợp đồng.
    • Xóa (biểu tượng thùng rác đỏ): Bỏ mẫu hợp đồng không còn dùng.

2. Thêm mẫu hợp đồng thuê

Bước 1: Bấm nút (+) Thêm mới ở góc trên bên phải màn hình.

Bước 2: Ở màn hình Thêm mẫu hợp đồng thuê, điền các thông tin sau:

  • Tên mẫu hợp đồng: Đặt tên để phân biệt với các mẫu khác.
  • Mô tả: Ghi vài chữ về nội dung hoặc lúc nào thì dùng mẫu này.
  • File hợp đồng thuê mẫu:
    • Tải file hợp đồng mẫu lên.
    • Lưu ý: Trong file, bạn đặt sẵn các mã code trường thông tin (ví dụ: họ tên, năm sinh, căn cước, số điện thoại, tên tòa nhà, căn hộ…). Khi ký hợp đồng, Resident tự điền thông tin khách thuê vào đúng chỗ.
  • Mặc định: Bật công tắc nếu bạn muốn lấy mẫu này làm mẫu mặc định.

Bước 3: Bấm Lưu là xong.

3. Sửa hoặc xóa mẫu hợp đồng thuê

  • Sửa: Bấm nút Sửa (bút xanh) ở dòng mẫu cần sửa → đổi nội dung → bấm Lưu.
  • Xóa: Bấm nút Xóa (thùng rác đỏ) ở dòng mẫu cần bỏ → xác nhận để xóa.

Danh sách mã code đầy đủ

Bạn đặt các mã dưới đây vào file Word (.docx) ở đúng chỗ cần điền. Khi tạo tài liệu, Resident thay mã bằng dữ liệu thật. Mã phân biệt chữ hoa chữ thường và phải giữ nguyên cặp ngoặc nhọn. Loại biểu mẫu này hiện có 134 mã.
